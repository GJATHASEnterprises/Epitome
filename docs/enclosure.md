# Epitome Step — Enclosure Specification (Sept 2026)

## Material baseline

| Model | Base shell | Top shell |
|---|---|---|
| Step Walnut | Black PETG | Wood-PLA (sanded + Danish oil) |
| Step Obsidian | CF-PETG | CF-PETG |

Legacy enclosure material/process options are removed from this plan.

## Shared mechanical constraints

- Two-tier stepped body.
- Wall thickness target: 2.4 mm.
- Coil window thickness: ≤1.5 mm.
- M3 heat-set inserts ×4.
- Rear USB-C recess + strain-relief channel.

## Obsidian lighting geometry

- Recessed side grooves with flush diffuser bars.
- WS2812B 8–12 LEDs per side.
- Glow lines only (LED dots not directly visible).
