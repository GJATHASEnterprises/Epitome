# Epitome — Marketing Plan (Batch 1)

**Budget target: ~$400 paid marketing**. No paid spend until real product photos and listings are live.

## Positioning

- **Step Walnut ($99):** minimalist / wood-desk buyer, warm premium aesthetic.
- **Step Obsidian ($109):** gamer / battlestation buyer, matte carbon + RGB glow-line identity.

## Channel allocation (~$400)

| Channel | Budget | Notes |
|---|---:|---|
| Etsy Ads (Walnut-led search terms) | $150 | Start low; kill if no traction |
| Meta/Instagram retargeting + short reels | $140 | Focus on creator-style demos |
| 2 gifted units to micro setup creators | ~$80 | Content + trust-building |
| Photo props/backdrop | $30 | Keep lean |
| **Reserve** | remainder | Includes trimmed Reddit test budget |

## Message guardrails

- Claims: “compatible with Qi-enabled devices”, “65W brick included with Step models”.
- Never claim Qi2/MagSafe certification unless certified.
- Lead with aesthetics + reliability (no brownouts, clean desk flow).

## Shipping note

Customer pays shipping. Run an A/B copy test after first sales:
- Variant A: clear checkout shipping estimate callout
- Variant B: “price excludes shipping” short disclosure above CTA
