# Epitome Step — Finishing Guide (Sept 2026)

## Walnut finishing (wood-PLA top shell)

1. Sand: 120 → 220 → 400 grit.
2. Clean dust fully.
3. Apply Danish oil (thin coat), wipe excess.
4. Allow cure; buff lightly.

## Obsidian finishing (CF-PETG shells)

- No paint system required.
- Light deburr only where needed.
- Preserve matte carbon-weave texture.

## Visual targets

- Walnut: warm, furniture-like top shell with subtle white status LED.
- Obsidian: clean matte carbon body with flush RGB glow lines and no exposed LED dots.
